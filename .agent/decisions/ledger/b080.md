# Picture-Frame Platformer Decision Ledger

## Batch 080

Questions 396-400 received no user selection. These choices define the first
Page 05 archive-module inventory, canonical scale grammar, functional pivot
contract, visible connection language, and per-section composition density.
They remain open to direct user override and grant no asset generation, runtime
implementation, rights-sensitive reuse, push, or deployment authority.

### 396. Page 05 Archive Module Inventory

Selection: build one fifteen-module `Archive Core`: three shared structural
modules, four paper/book modules, four furniture/catalog modules, and four
frame/artifact modules. Each visual module receives stable identity, canonical
spatial and socket contracts, material/tier/fallback/provenance bindings, and
an independent semantic companion. Critical silhouettes and mechanisms remain
custom Lost Pages work; donors and procedural forms remain bounded to
noncritical surfaces, support, backing, braces, or dressing. JR, hazards,
discoveries, and portal remain separate catalogs.

Rationale:

- Fifteen modules balance section identity with deliberate cross-variant reuse.
- Closed identity and semantic companionship preserve deterministic assembly.
- Separate source roles prevent inventory availability from defining gameplay.

### 397. Page 05 Archive Module Scale Grammar

Selection: set canonical aperture `W = 1`, `H = 2W/3`, and JR height
`J = 0.09W`. Classify removable microdetail below `0.25J`,
character-scale details at `0.25J-1J`, traversal spans at `1J-3.5J`, and
structural/landmark spans at `3.5J-8J`. Pin each module's exact spatial
contract and use unit-scale recipe instances. Only the validated uniform course
root may convert to host meters. Donors adapt explicitly, invalid fit rejects,
and every tier preserves critical silhouette and contact.

Rationale:

- JR-relative bands preserve physical readability and miniature-world scale.
- Unit-scale instances prevent variant-specific collision and socket drift.
- One uniform host conversion keeps wall and tabletop gameplay comparable.

### 398. Page 05 Module Pivot and Orientation

Selection: use one typed `Functional Origin`. Align default poses to canonical
frame axes. Place traversal origins at entry supports, static structural
origins at primary mount/contact centroids, mechanism origins on authoritative
motion axes, and dressing origins at declared mounts. Pin origin,
orientation, and finite symmetries as semantic identity. Imported assets adapt
once; mesh centers, source pivots, post-solve offsets, arbitrary mirrors, and
camera-facing corrections remain non-authoritative.

Rationale:

- Functional origins express actual support and movement intent.
- Stable pivots make socket solve, revision comparison, and replay reproducible.
- One adapter isolates native asset coordinates below semantic placement.

### 399. Page 05 Module Connection Appearance

Selection: use one typed `Conservation Join` family bound to exact accepted
semantic edges. Paper/books use tongues with stitches or fold scores;
wood/furniture use dovetails or tenon shadows with brass pins; frame/artifact
connections use repair keys, clamps, or saddles. Traversal joins preserve
continuous top silhouettes, collider seams, non-color edges, and cues. Visible
braces may present or validate a join but never move endpoints or infer
topology. Accessible tiers retain stable non-color join marks.

Rationale:

- Material-specific joins reinforce the conserved impossible-archive identity.
- Exact edge bindings prevent visible proximity from becoming topology.
- Continuous traversal seams preserve platforming readability and fairness.

### 400. Page 05 Section Composition Density

Selection: use one progressive `Readable Bay` budget with at most six, eight,
and ten archive-module instances across Sections 1-3. Pin the accepted semantic
set identically across C1/C2/C3. Permit at most one, two, and four neutral
dressing instances per section by tier. Preserve one primary focal mechanism,
the existing two-active-hazard cap, and unobstructed reads of JR, next landing,
hazard or transition cue, and goal direction. De-emphasize depth through static
contrast rather than hiding semantics.

Rationale:

- Progressive density matches the one/two/three-lane teaching arc.
- Semantic invariance prevents performance class from changing gameplay.
- Focal and route visibility limits keep the richer archive readable.
