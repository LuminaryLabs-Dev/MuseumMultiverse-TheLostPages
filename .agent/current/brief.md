# Provisional Player Experience: Page 05

Status: discovery only

Authority: evidence-based self-answers, not user-approved design

## Promise

JR enters a living picture frame, rearranges its layered paper world, and then
platforms through the route he created to recover Page 05's portal fragment.

## Shared Journey Foundation

- All eight Lost Pages use the same deterministic platformer, renderer,
  command, collision, checkpoint, failure, recovery, completion/reward, and
  semantic-save contracts while keeping distinct recipes, art, themes, and
  physical host adapters. Page 02 teaches the frame language; Page 05 delivers
  its full layered picture-frame form.
- Each wall, tabletop, or floor host validates placement and hands gameplay one
  immutable meter-scale descriptor containing canonical origin, quaternion,
  gravity, support/contact, safe-zone, capability, anchor identity, and revision
  fields. Activation pins it; tracking drift pauses and revalidates outside
  gameplay.
- Every route is authored in canonical gameplay coordinates. One uniform root
  scale inside a calibrated physical/readability/safety interval applies to
  visuals, semantic collision, anchors, sockets, and cues without changing
  normalized Jump, hazard, route, or timing truth. Failure to fit uses
  re-placement or an authored fallback.
- Players reuse placement, `Start Run`, fixed `Jump`, one clearly labeled
  contextual action, pause/return, and matched recovery heroes. Only current
  heroes appear first; optional controls use foldouts. Touch, keyboard, switch,
  and supported gamepad inputs preserve command, focus, and announcement
  meaning.
- One versioned semantic save namespaces each route's checkpoint, completion,
  assistance, and discoveries and maintains an idempotent journey-wide
  completion/reward ledger. Atomic copy-on-write migration isolates bad route
  state, separates route restart from confirmed all-progress reset, and never
  stores camera, room, WebXR, renderer, cache, or diagnostic records.
- Every route adds one dominant signature mechanic through a closed versioned
  recipe extension, teaches it safely, and provides an accessible equivalent
  and fallback without changing shared gameplay or host ownership.
- The current stories become platformer actions: Page 01 chooses branching
  maze routes; Page 02 changes frame paths with glyphs; Page 03 uses moving
  sketches; Page 04 rebuilds paths with words; Page 05 transforms layered
  picture routes; Page 06 sorts lanes; Page 07 reveals hidden paths with light;
  and Page 08 powers sockets and the final portal.
- Learning accumulates in that order. Page 05 combines only taught
  fundamentals, Page 08 uses a declared small mastery subset, route-local
  assistance remains available, and optional discoveries never block progress.
- Standard first clears target four to six minutes; Page 05 and Page 08 target
  seven to nine. Short taught sections save atomically at intervals of no more
  than about ninety seconds of active play. Global play is untimed, local
  hazard timers pause with the game, and shorter mastery replays award the same
  rewards.
- Signature data may describe only allowlisted route, platform, hazard,
  contextual-action, checkpoint-local state, and feedback transitions.
  Authoring, CI, and activation validate replay, reachability, accessible
  fallback, migration, and budgets; arbitrary code and host, renderer, shared
  physics, global save, completion, or reward authority are forbidden.
- Hero landmarks share dormant, inviting, active, checkpoint-transformed,
  goal-ready, complete, and blocked/recovery presentation states with
  route-specific visual, text, audio-intent, and haptic-intent descriptors plus
  non-color, reduced-motion, silent, and screen-reader equivalents. Gameplay
  state remains authoritative.
- Story-native placement uses walls for Pages 01, 02, 04, 05, and 07,
  tabletops for Pages 03 and 06, and a floor or low pedestal for Page 08.
  Explicit tabletop fallbacks preserve the same gameplay and progression for
  wall routes.
- Gallery-wall, tabletop book/diorama, and floor/pedestal-portal scale families
  provide validated viewing, safe-zone, JR/cue readability, reach, depth, and
  performance limits. Routes may tighten but not loosen them, and fallback
  never changes canonical simulation.
- Landmark transformations persist semantic state at a safe boundary and pause
  play until one bounded presentation acknowledgment. Reduced-motion and silent
  equivalents are first-class; a failed presentation uses an approved
  accessible static final state without losing progress or rewards.
- A surface-family change occurs only before activation or at an atomic
  checkpoint/recovery/re-placement boundary after complete validation, pinning,
  and player confirmation. Active play never morphs, and an unqualified new
  placement preserves the save for retry or return.
