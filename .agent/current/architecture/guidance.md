## Guidance Render Boundary

Provisional Batch 058 keeps objective and placement owners responsible only for
one semantic cue descriptor containing stable cue/action/target ids, urgency,
concise accessible intent, allowed presentation forms, and an optional
target-local cue socket. The host may bind that socket only through the
accepted anchor generation and normalized placement descriptor.

The renderer selects among a world-locked marker for a valid visible target, a
screen-edge projection for the same valid off-camera target, or a
screen-centered recovery instruction when no trustworthy target pose exists.
It owns projection, safe-area layout, critical-mask avoidance, and equivalent
visual/audio-intent/haptic/accessibility presentation, but it cannot synthesize
a target, change the semantic action, confirm placement, or advance gameplay.
Stale anchors and failed projections remove directional claims and route back
to placement recovery. This is a candidate contract, not implemented behavior.
