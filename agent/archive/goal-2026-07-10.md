## Product Goal

Lost Pages is an eight page AR companion magazine for Museum Multiverse.

Each printed page should have a QR code. Each QR code should open a public
static route. Each route should launch a page-specific web, debug, or AR
experience.

The repo must support print-facing page composition, phone-ready QR targets,
static GitHub Pages deployment, desktop debug routes, mobile AR routes, short
deploy messages, durable handoff state, and state-alignment turns.

## Eight Experience Quality Goal

All eight QR routes should become complete, replayable, simple strategy
experiences rather than small interaction demos.

The prior quality target requested:

- one clear launch action;
- an observe, choose, act, feedback, adapt, complete loop;
- 100-300+ deterministic authored or generated world objects per experience;
- an active-simulation budget;
- success, failure, reset, replay, reward, and cross-page progression;
- visible interaction, animation, audio, VFX, camera, and completion feedback;
- desktop, phone-route, and real-AR proof.

The fixed object-count requirement is intentionally preserved here for Pass 3
adjudication rather than silently carried into the new canonical goal.

## Prior Architecture Goal

NexusEngine was selected as the target runtime architecture. Reusable mechanics
were to use stable Domain Service Kit identities, explicit deterministic state
and inputs, reset and snapshots, headless validation, renderer independence,
and `engine.n.*` APIs. Lost Pages retained story, page manifests, descriptors,
routes, QR behavior, and presentation adapters.

## Prior Generic Page Structure

The earlier goal used generic roles:

- Page 01: cover and entry portal
- Page 02: artifact page
- Page 03: character or exhibit page
- Page 04: museum map or path page
- Page 05: lore fragment page
- Page 06: interactive object page
- Page 07: hidden or unlock page
- Page 08: back page and final portal

That list was superseded by the registered eight-page experience map and the
future Pass 3 final specifications.

## Preserved Boundary

Lost Pages owns the magazine, copy, routes, QR structure, page data, print
presentation, authored descriptors, and experience compositions. Reusable
runtime behavior belongs in NexusEngine Domain Service Kits or the NexusEngine
ProtoKit path.
